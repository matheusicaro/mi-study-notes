# Private Helpers

Personal knowledge base for generic dev/study reference: cloud/AWS notes, software design references, reusable code snippets, and study guides.

## Structure

- **[cloud/](/cloud/README.md)** — AWS CLI commands and tutorials (SSL certs, Elastic Beanstalk, CodePipeline, domain redirects, Kubernetes).
- **[software-design/](/software-design/README.md)** — Architecture references: frontend architecture, SaaS patterns, system-design patterns (API gateway, load balancing, caching, stateless/stateful, monolith vs microservices), diagrams.
- **[code-snippets/](/code-snippets/README.md)** — Reusable code and cheatsheets: Mongo queries, SQL/databases (SQL vs NoSQL, Elasticsearch, joins, PostgreSQL vs MySQL), JavaScript/Jest tips, Java utilities (encryption, converter, date, regex, string), and small scripts.
- **[guides/](/guides/)** — Study guides: design patterns, folder structure conventions, Node.js, React.
- **[coding-exercises/](/coding-exercises/README.md)** — Worked coding-challenge solutions.
