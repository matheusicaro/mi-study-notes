## Edit System File by CLI

##### Mac IOS / Linux

```powershell
# open file   -     <FILE> => [ .zshrc, .bash_profile ] => Example: sudo vim ~/.zshrc
sudo vim ~/<FILE>

# exit file
ctrl+c 

# set command
Digit ˜:˜

# save and close file command
Digit “wq”

# confirm
Digit Enter

```
